# WS001 Cバス用語集

最終更新: 2026-08-31

対象Phase: `ws001p001`

本書ではNEC資料の原名を保持しつつ、RTL・回路図で誤読しにくい正規名を併記する。信号の完全な命名規則は`ws001p002`で確定する。

| 用語・原名 | 意味 | 設計上の注意 |
| --- | --- | --- |
| Cバス | PC-9800シリーズの拡張スロットバスの通称。NEC資料では「拡張用スロットバス」または製品仕様上「汎用拡張スロット」と表記される。 | ISAと似た信号があっても同一仕様として扱わない。 |
| 80286/386/486/Pentiumタイプ | NEC資料がCPU世代別に区別する後期スロット信号契約。 | 8086/µPD70116タイプとの差と、後期機内の機種差を別々に管理する。 |
| `0`/`1`極性接尾辞 | NEC信号名末尾の極性表記。例: `IOR0`はアクティブLow、`SCLK1`は正論理。`AB001`はアドレスbit 00の正論理表記として読む。 | RTLでは例として`cbus_ior_n`のように極性を明示し、原名を台帳に残す。 |
| `AB00-AB23` | 24-bitアドレスバス。NEC原表では`AB001-AB231`。 | 旧20-bitボードとの互換処理が機種側に存在する。全24 bitデコードの有無を区別する。 |
| 20-bit互換デコード | AB00-AB19で1 MiB空間を扱う旧ボード互換モード。 | AB20-AB23の物理ピンが存在しないという意味ではない。80286以降機のAB19互換切替も考慮する。 |
| 24-bitフルデコード | AB00-AB23をすべてデコードして最大16 MiB空間を区別する能力。 | CPU世代名だけで有効と断定せず、機種、スロット、ボード設定を互換性台帳で扱う。 |
| `DB00-DB15` | 16-bit双方向データバス。NEC原表では`DB001-DB151`。 | データ方向とOEはサイクル種別・所有権から導出し、常時双方向駆動しない。 |
| `AB00` | アドレスbit 0。下位バイトレーン選択も兼ねる。 | `BHE`と組み合わせて8/16-bit、奇偶バイトを判定する。 |
| `BHE` | Bus High Enable。上位データバイトの選択。NEC原名`BHE0`。 | アクティブLow。AB00との真理値は`ws001p003`で固定する。 |
| `IOR` / `IOW` | I/O read / writeストローブ。NEC原名`IOR0`/`IOW0`。 | アクティブLow。V13のsetup/holdは未確認。 |
| `MRC` / `MWC` | Memory read / write command。NEC原名`MRC0`/`MWC0`。 | メモリサイクルを初期製品に含める範囲は後続Phaseで限定する。 |
| `MWE` | Memory write enable。NEC原名`MWE0`。 | MWCとの役割差とタイミングをNECタイムチャートから転記する。 |
| `IORDY` | CPU/内部DMAに対するウェイト要求。NEC原名`IORDY1`。 | カード側トライステート出力。無限ウェイトを許さず、Low幅上限と内部タイムアウトを設ける。 |
| `SCLK` | Cバスへ供給されるシステムクロック。NEC原名`SCLK1`。 | CPUクロックそのものと仮定しない。V13実周波数は未確認。 |
| `S18CLK` | 307.2 kHzクロック。NEC原名`S18CLK1`。 | 初期ターゲットブリッジでの用途は未定。 |
| `POWER` | +5 V電源確定信号。NEC原名`POWER0`。 | アクティブ条件だけに安全性を依存せず、FPGA未設定時も外付けOEでHigh-Zにする。 |
| `RESET` | 本体リセット信号。NEC原名`RESET0`。 | アクティブLow。電源投入、コンフィグ、クロック未確立を含む独立安全条件が必要。 |
| `IR3`等 | CバスからPICへ入るマスク可能割り込み要求。NEC原名は`IR31`等。 | 正エッジ要求とされる。線ごとのオープンコレクタ/トライステート差とV13競合を確認する。 |
| `IOCHK` | ノンマスカブル割り込み要求。NEC原名`IOCHK0`。 | 初期実装では使用しない。誤駆動は重大なため物理的に無効化する候補。 |
| `DRQ` | 従来DMACへのDMA request。 | チャネルと物理ピンが機種・スロットで変わるため、論理チャネル名を物理端子へ固定しない。 |
| `DACK` | 従来DMACからのDMA acknowledge。 | チャネルとスロット割当をDRQと対で管理する。 |
| `WORD` | 従来DMAのワード/バイト選択。NEC原名`WORD0`。 | ワード転送時LowでDACK同期。ノーマルモードはバイトのみとの記述がある。 |
| `DMATC` | DMA terminal count。NEC原名`DMATC0`。 | 最終ワード/バイトでLow。エッジだけでなくレベルとして扱う。 |
| `EXHRQ1/2` | 後期CPUタイプの外部CPU/DMAからのホールド要求。 | 2系統は優先度が異なる。V13対応は未確認。 |
| `EXHLA1/2` | EXHRQに対するホールド許可。 | 許可前にカード側がバスを駆動してはならない。 |
| `SBUSRQ` | 内部DMAまたはリフレッシュのためのバス解放要求。NEC原名`SBUSRQ1`。 | 外部マスタは検出後ただちに要求解除・駆動停止する必要がある。 |
| `SALE` | 上位アドレスラッチ要求。NEC原名`SALE1`。 | AB17-AB23のラッチ条件として使用される。世代・機種別タイミングは未確認。 |
| `MACS` | メモリボード自己アクセス信号。NEC原名`MACS0`。 | オープンコレクタとされる。受動I/OターゲットMVPには含めない。 |
| High-Z | 出力ドライバがバスから電気的に切り離された状態。 | FPGA内部の`oe=0`だけでなく、外付けレベル変換器の`OE`でも保証する。 |
| BFM | Bus Functional Model。Cバスの要求・応答をシミュレーションで生成・監視するモデル。 | S001の世代別タイミングと機種固有の未確認値をパラメータで分離する。 |
| 対象機固有値 | PC-9800の機種、CPU世代、スロット番号、装着ボード、実機状態に依存する値。 | `family-confirmed`の値で一律に埋めず、互換性マトリクスと未確認IDで管理する。 |
