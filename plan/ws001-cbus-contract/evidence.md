# WS001 Cバス証拠台帳

最終更新: 2026-08-31

対象Phase: `ws001p001`

互換目標: PC-9800シリーズ全般

初期実機候補: PC-9821V13 + Cバスユニバーサル基板 + Tang Nano 20K

## 1. 台帳の使い方

本書は、後続設計が出典のない通説やISAからの類推を確定事項として扱わないための証拠ベースラインである。信号の完全な機械可読マトリクスとタイミング契約は、それぞれ`ws001p002`と`ws001p003`で作成する。

### 証拠優先度

| 優先度 | 種別 | 用途 |
| --- | --- | --- |
| `P0` | 特定機種のメーカー資料または対象実機の測定 | その機種・スロットに固有な値の確定に使用できる。 |
| `P1` | メーカーの同一バス系列資料 | Cバス共通契約の主根拠。対象機差は別途確認する。 |
| `P2` | 部品・ボードメーカー資料 | FPGA、変換回路、開発ボード側の根拠。Cバス仕様の代用にはしない。 |
| `P3` | 出典を示す技術書、ボード取扱説明書、技術解説 | 相互照合と資料探索に使用する。単独では対象機固有値を確定しない。 |
| `P4` | 既存実装、Web記事、エミュレータ、伝聞 | 仮説生成とテスト項目の発見にだけ使用する。 |

### 判定語

| 判定 | 意味 |
| --- | --- |
| `target-confirmed` | PC-9821V13の一次資料または対象実機測定で確認済み。 |
| `family-confirmed` | NECのCバス系列資料で確認済みだが、PC-9800全機種の差分は未確認。 |
| `vendor-confirmed` | 対象部品または開発ボードのメーカー資料で確認済み。Cバス側の仕様確定には使わない。 |
| `cross-checked` | 独立した補助資料でも一致する。 |
| `inferred` | 複数事実から合理的に推定できるが、確定に使わない。 |
| `unknown` | 根拠不足、矛盾、または対象機差が残る。 |

| `U-TANG-001` | Tang Nano 20Kの実ボード版数と、共有されるオンボード周辺回路を安全に無効化できる条件が未確認。 | 34本すべてを自由なGPIOとして数えられず、High-Z保証を確定できない。 | 実ボードのシルク/版数を確認し、対応回路図と実装部品を照合する。 | p002, WS002 |

## 6. 実測再開条件

測定器がない現状では、PC-9800各世代の固有値を推測で埋めない。実測を計画するときは、次を最低条件とする。

- 対象実機の完全型番、背面、装着済みボード、スロット番号の記録
- Cバス延長/ブレークアウトとGNDを先に接続できるテストポイント
- DMMと電流制限、ヒューズまたは保護抵抗を備えた段階的給電
- 5 V入力に対応するロジックアナライザプローブ
- SCLK、RESET、POWER、IOR/IOW、IORDY、DB、ABを観測できるチャネル計画
- 出力は初回試験で常時High-Zとし、入力観測だけから開始する手順
- バス競合とエッジ品質を確認する段階ではオシロスコープを使用する手順
